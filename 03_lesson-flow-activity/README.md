Activity: OER Development & Lesson Flow
=======================================

The purpose of this activity is for ACT-CMS Fellows to develop a familiarity
with the technical aspects of developing their proposed lesson(s), including
JupyterLab, ChemCompute, and the Lesson Flow version control framework.

## Lesson Information
### Lesson Learning Outcomes
At the end of this lesson, ACT-CMS Fellows will be able to...

1. Use GitHub to create a new lesson repository within the ACT-CMS organization
from the `act-cms/lesson-cookiecutter` template repository (`origin`);
2. Use `git`/GitHub Desktop to make a local clone of their lesson repository
(`local`);
3. Use `git`/GitHub Desktop to navigate the branches of `local`;
4. Use JupyterLab to customize the activity template by developing part of a
Python basics lesson for their target course;
5. Use `git`/GitHub Desktop to diff, stage, and commit local changes to the
activity template to the branch `local:contrib`;
6. Use `git`/GitHub Desktop to push their local commit(s) from `local:contrib`
to `origin:contrib`

### Cyberinfrastructure Prerequisites

Before beginning this lesson, Fellows are expected to...
1. Complete the setup of their local machine according to the steps outlined
in [Chapter 2: Setup for ACT-CMS Fellows](02_fellow-setup.md)
2. Be familiar with basic Python programming and syntax, at the level of the
[Introduction to Programming for Molecular
Scientists](https://act-cms.molssi.org/portal/lessons/foundational-intro-python/)
lesson on the ACT-CMS Portal

There are no content prerequisites for this activity.

## Lesson Versions & Intended Modalities

This activity itself is designed to be delivered in a synchronous modality
utilizing LiveCoding pedagogy, however the companion tutorial with chapters
written in static, GitHub-flavored Markdown is provided as an asynchronous
reference with step-by-step discussion of the Lesson Flow.
